# Podstawowa struktura dokumentu HTML

Każdy dokument HTML posiada określoną strukturę, która definiuje sposób interpretacji strony przez przeglądarkę.

### Podstawowe elementy:
- **`<html>`** - główny element języka HTML, jest głównym kontenerem całego dokumentu.
- **`<head>`** - znajduje się bezpośrednio wewnątrz znacznika HTML, zawiera metadane o stronie, czyli ustawienia i informacje nie wyświetlane bezpośrednio użytkownikowi.
- **`<body>`** - znajduje się bezpośrednio wewnątrz znacznika HTML, zawiera właściwą treść strony, którą widzi użytkownik - tekst, obrazy, nagłówki, odnośniki, listy, formularze itd.

Dodatkowo, na początku dokumentu umieszcza się znacznik **`<!DOCTYPE html>`**, który informuje przeglądarkę, że strona jest napisana w najnowszej wersji języka HTML (HTML5).
