# Implementacja interfejsu użytkownika

### Lekcja przedstawia sposób tworzenia własnej strony na bazie innej istniejącej strony

W ramach lekcji odwzorowaliśmy główne elementy interfejsu strony https://getbootstrap.com/docs/4.0/examples/album/. Realizacja polegała na utworzeniu własnej strony z pomienięciem jak największej liczby zbędnych elementów ze strony.

Lekcja ma pokazać, że przy odwzorowywaniu strony nie należy w pełni kopiować kodu strony bazowej, tylko wybierać interesujące nas elementy i aplikować je w odpowiedni, wybrany przez nas sposób.
