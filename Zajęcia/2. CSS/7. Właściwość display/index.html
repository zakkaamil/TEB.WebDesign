Właściwość display

Domyślne wartość - inline i block

Elementy liniowe, takie jak span, a mają domyślnie display: inline; Wartość inline sprawia, że element zajmuje tyle szerokości, co jego zawartość. Takie elementy wyświetlają się jeden obok drugiego.

Przykłady:

Element span Link

Elementy blokowe, takie jak div, section, h1, h2... mają domyślnie display: block; Wartość block sprawia, że element zajmuje całą dostępną szerokość (szerokość strony lub jego kontenera). Takie elementy wyświetlają się jeden pod drugim.

Przykłady:

Element div

Element akapit

display: inline-block

Wartość inline-block działa tak samo jak inline, ale dodatkowo element reaguje na właściwości width i height. Oprócz tego lepiej współpracuje z margin-top i margin-bottom.

Przykłady:

Blok jako inline-block
Blok jako inline-block

display: flex

Wartość flex wprowadza całkowicie inny sposób interpretacji w ustawianiu elementów. Następuje podział na kontener i jego dzieci. Kontener z display: flex; zajmuje całe dostępne miejsce. Dzieci w kontenerze zachowują się podobnie do elementów z display: inline-block;. Dzięki różnym opcjom zyskujemy sporą kontrolę nad elementami w kontenerze
