# Podstawowe znaczniki HTML

### Lista z opisem znaczników HTML, które pojawiają się w pliku **podstawowe_znaczniki.html**.

- **`<!-- ... -->`** – komentarz w kodzie, ignorowany przez przeglądarkę.
- **`<h1>` ... `<h6>`** – nagłówki różnego poziomu; `h1` jest największy, `h6` najmniejszy.  
- **`<b>`** – pogrubienie tekstu (bez nadania znaczenia semantycznego)
- **`<i>`** – kursywa (bez nadania znaczenia semantycznego) 
- **`<p>`** – akapit, element blokowy służący do grupowania tekstu.  
- **`<hr />`** – pozioma linia oddzielająca treść.  
- **`<br />`** – wymuszenie przejścia do nowej linii w tekście.  
- **`<span>`** – element liniowy, służy do wyróżniania fragmentów tekstu w obrębie tej samej linii.  
- **`<div>`** – element blokowy używany do grupowania innych elementów lub tworzenia sekcji na stronie.
- **`<a>`** – odnośnik (link) do innej strony lub elementu.
- **`<img>`** – wstawia obraz do strony.  
- **`<ol>`** – lista numerowana (uporządkowana).
- **`<ul>`** – lista nienumerowana (nieuporządkowana).
- **`<li>`** – pojedynczy element listy.
