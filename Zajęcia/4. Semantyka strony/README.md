# Semantyka strony

### Czym jest semantyka?

Semantyka w HTML oznacza **nadawanie znaczenia elementom strony** poprzez używanie odpowiednich znaczników.  
Zamiast stosować ogólne znaczniki, takie jak `<div>` czy `<span>`, semantyczne elementy HTML opisują **rolę i znaczenie** danej części strony — dzięki czemu kod staje się bardziej czytelny, logiczny i dostępny.

Semantyczne znaczniki pomagają:
- wyszukiwarkom (SEO) lepiej rozumieć strukturę treści,  
- technologiom asystującym (np. czytnikom ekranu) w interpretacji zawartości,  
- przeglądarkom w lepszym renderowaniu i interpretacji strony.

### Przykładowe znaczniki semantyczne HTML5

- **`<header>`** – nagłówek strony lub sekcji, często zawiera logo, tytuł lub menu nawigacyjne.  
- **`<nav>`** – sekcja przeznaczona na nawigację po stronie (np. menu linków).  
- **`<main>`** – główna, unikalna część dokumentu, zawierająca zasadniczą treść strony.  
- **`<section>`** – logiczna sekcja strony, grupująca powiązaną tematycznie zawartość.  
- **`<article>`** – samodzielny, niezależny fragment treści, np. wpis na blogu, artykuł, post.  
- **`<aside>`** – treść poboczna, np. panel boczny, spis treści, przypisy, reklamy.  
- **`<footer>`** – stopka strony, często zawiera informacje o autorze, prawa autorskie lub linki pomocnicze.  
- **`<figure>`** – element grupujący treści graficzne, np. obraz lub wykres, wraz z podpisem.  
- **`<figcaption>`** – podpis lub opis dla elementu umieszczonego wewnątrz `<figure>`.
